# Client

The `client/` directory contains the frontend application for the public-service web project.

## Responsibilities

- Build the user interface
- Provide responsive layouts
- Implement accessible navigation
- Support keyboard-only interaction
- Provide accessible forms and search
- Display data received from the server API

## Accessibility

The client will follow accessibility best practices, including:

- Semantic HTML
- Proper heading structure
- Labels for form controls
- Visible keyboard focus
- Accessible buttons and links
- Meaningful alternative text for images
- Accessible error and status messages
- Appropriate ARIA attributes when required
